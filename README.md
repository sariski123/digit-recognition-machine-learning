# Machine Learning Case Study: Digit Classification 
This is a project generated after a 30h course I took about AI and ML in the BISITE Research Group. It explores several Machine Learning and Neural Networks models to recognize digits from 8x8 and 28x28 images.

Abstracto: This paper addresses the problem of handwritten character recognition. Several classical machine learning models (k-Nearest Neighbors and Support Vector Machines), dimensionality reduction techniques (Principal Component Analysis), a neural network with a single hidden layer (multilayer perceptron), and a convolutional neural network (CNN) are compared. The objective is to analyze the different results, optimize the neural network, and determine the necessity of using a convolutional network as the problem increases in level of difficulty.
